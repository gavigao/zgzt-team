# 产品决策记录

## 内容集中沉淀

将比赛、队员、训练、新闻、荣誉和照片放在同一平台，降低信息分散在群聊和个人文件中的维护成本，并为长期回顾保留结构化入口。

## 登录账号与公开用户名分离

登录账号需要唯一且稳定；公开用户名应允许修改和重名。两者分离后，成员可以调整展示名，而历史评论、帖子和点赞仍通过内部用户 ID 正确关联。

## 权限分层

访客浏览公开内容；注册用户参与互动；管理员维护内容；总负责人管理管理员。角色在服务端实时读取，避免仅依赖旧 JWT 中的角色声明。

## 社区隐私

点赞仅公开计数，不公开点赞者名单；个人头像与官方队员档案照片分离；未来补充队员资料时，需要明确字段公开范围与本人授权。

## 内容治理边界

当前由管理员处理不当内容。后续以小型球队社区的实际规模为前提，增加基础限流、必要操作记录和清晰的删除规则，而不引入过度复杂的风控体系。
