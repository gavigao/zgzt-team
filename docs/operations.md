# 运维说明

## 上传文件

`backend/public/uploads/` 属于生产数据，不可用 Git 重建。禁止使用 `git clean`、批量删除或部署脚本覆盖该目录。

## 发布后检查

- `pm2 status` 确认 `zgzt-team` 运行；
- 检查 `http://127.0.0.1:3002/api/health`；
- `nginx -t` 后再 reload；
- 检查关键页面、登录、管理权限、图片与 API。

PM2 重载后首次健康检查可能过早；先确认进程状态和端口监听，再判断是否故障。

## 常见问题

| 现象 | 检查方向 |
| --- | --- |
| 页面 403 | 检查 `frontend/dist` 是否可被 Nginx 读取 |
| 上传返回 413 | 检查 Nginx 与应用的 5 MB 限制是否一致 |
| 后端无法连接 | 检查 PM2 日志、端口与 `backend/.env`，不要打印 `.env` 内容 |
| Git 拉取被阻止 | 先识别并保留运行时数据，禁止直接 reset 或 clean |

## 安全边界

- 不在文档、日志或 SQL 中记录密码、Token、数据库凭据或 SSH 信息；
- 生产 CORS、限流、账号恢复和图片文件签名校验属于后续安全事项，见项目开发进度；
- 忘记密码处理应避免在聊天记录或共享文档中传递明文密码。
